# GenAI IP Registration Challenge

Build a GenAI app or agent that automatically registers its input or output as IP assets on Story.

Challenge Description
abv.dev provides AI infrastructure with built-in Story Protocol integration. This bounty challenges you to create any generative AI application—chatbot, image generator, content creator, agent—that uses abv.dev to register the AI's creations or prompts as intellectual property on Story Protocol.

About abv.dev
abv.dev is a GenAI platform that makes it easy to build AI applications with built-in IP protection. Their Story Protocol integration lets you register AI-generated content as on-chain IP assets without extra setup.

What to Build
Create a GenAI application or agent that:

Uses abv.dev's platform for AI generation
Registers either input (prompts) or output (generated content) as IP assets on Story Protocol
Leverages abv.dev's built-in Story Protocol integration
Examples: AI art generator that mints each creation as IP, content agent that registers its outputs, prompt marketplace with IP protection.

Requirements
Must use abv.dev platform
Must register content as IP assets on Story Protocol using abv.dev's integration
Can register input, output, or both
