# Detailed Compression Scenarios

## PLACEHOLDER TEST 1: Standard Dialogue Scene

**Objective**: Test basic semantic extraction and reconstruction of a 2-person dialogue.

**Input**: 2 minute video clip, 1080p.
**Projected Output**: JSON structure containing:
- Dialogue transcript
- Sentiment analysis per line
- Basic blocking (movement) data
- Lighting cues

**Status**: Theoretical Model Only.

## PLACEHOLDER TEST 2: High Motion Action

**Objective**: Test limits of semantic description for fast-paced movement.

**Input**: 30 second chase sequence.
**Projected Output**: JSON structure containing:
- Entity tracking (Car A, Car B)
- Vector motion paths
- Physics approximation

**Status**: Theoretical Model Only.

## PLACEHOLDER TEST 3: Low Light/Noisy Audio

**Objective**: Test error correction capabilities.

**Input**: 1 minute clip with poor lighting and background noise.
**Projected Output**: Cleaned semantic intent (what *should* be there vs what *is* there).

**Status**: Theoretical Model Only.
