## Image Distillation Prompts

This folder will contain **semantic distillation prompts for images**, focusing on:

- Core visual content (entities, composition, actions)
- Style and rendering characteristics
- World rules and contextual cues that matter for regeneration

Current templates:

- `base-image-distillation.md` – Generic image distillation
- `illustration-concept-art-distillation.md` – Placeholder for stylised art and concept pieces
- `photograph-documentary-distillation.md` – Placeholder for realistic / documentary photography

These are initial placeholders and can be extended or deepened as the image semantics work evolves.
