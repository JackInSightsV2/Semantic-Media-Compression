## Text Distillation Prompts

Text content needs **different distillation lenses** depending on genre and purpose.

This folder defines **prompt templates** for:

- `base-text-distillation.md` – Generic text distillation (fallback / default)
- `short-story-distillation.md` – Narrative fiction, character-driven
- `essay-argumentative-distillation.md` – Opinion / argument essays
- `technical-report-distillation.md` – Technical / analytical reports and papers
- `product-spec-distillation.md` – Specs, design docs, requirements

You can extend this set with additional genres (e.g. marketing copy, tutorials, policy documents) while keeping the same structure.
